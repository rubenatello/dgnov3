# OG Image Specifications for DGNO

## Required OG Image
You need to create and upload a default OG image to Firebase Storage at:
`/images/og-default.jpg`

## Specifications
- **Dimensions**: 1200x630 pixels (Facebook/Twitter recommended)
- **Format**: JPG or PNG
- **File size**: Under 8MB (ideally under 1MB)
- **Content**: Should include DGNO branding and tagline

## Suggested Design Elements
- DGNO logo prominently displayed
- Background with your brand colors
- Text: "Data-Driven Government News & Insights"
- Clean, professional design
- High contrast for readability

## Upload Instructions
1. Create the image using any design tool (Canva, Photoshop, etc.)
2. Save as `og-default.jpg`
3. Upload to Firebase Storage at `/images/og-default.jpg`
4. Make sure the file has public read permissions

## Alternative Option
If you don't have a design tool, you can use Canva's free templates:
1. Go to canva.com
2. Search for "Facebook Cover" (same dimensions as OG image)
3. Customize with DGNO branding
4. Download as JPG

The SEO implementation will automatically use this image for articles that don't have a specific featured image.
